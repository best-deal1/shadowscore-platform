# Product polish release

## Pages improved

- Pricing now presents one Executive Report purchase instead of plan-like choices.
- Sample Report now has the global product shell, a clear introduction, and a focused purchase path.
- Methodology now uses the global product shell.
- Report payment, processing, and reading surfaces now provide clearer return paths.
- Global loading, error, and 404 states now provide recovery actions.

## Navigation improvements

- Public pages share a consistent breadcrumb and Home path.
- The skip link provides direct keyboard access to page content.
- Footer links now point to the canonical Sample Report and Methodology pages.
- Report pages link back to Investigations and Archive.

## Consistency improvements

- Public navigation, page context, CTA hierarchy, and recovery states use the shared product language and visual system.
- Pricing and report purchase copy use the same one-time purchase model.

## Customer clarity improvements

- Pricing explains when payment occurs, what it produces, and who processes payment.
- Sample Report sets expectations before presenting demonstration evidence.
- Error states explain the next available action without exposing technical details.

## Remaining limitations

- Email notification is not available while an Investigation is processing.
- Report access requires the purchasing Account.
- Public source availability can limit evidence coverage and confidence.
